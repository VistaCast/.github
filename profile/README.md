# VistaCast · 视界云遥

**AI Visual Autopilot** — 纯软件 AI 摄像头云监控。

把线下店铺、仓储、工厂变成可分析的数字化视频流。兼容海康、大华、宇视、TP-Link VIGI 等 **ONVIF / RTSP** 工程机；消费款厂商 App 私有云机不在范围。

## 与 VistaRemote

VistaCast 做**固定摄像头视觉**；[VistaRemote](https://github.com/VistaRemote) 做**远程桌面操控**。二者并存，代码与组织分离。
